# Downloaded Papers

## Core Papers (Copy Mechanisms)

1. **Pointer Networks** (Vinyals et al., 2015)
   - File: `1506.03134_pointer_networks.pdf`
   - arXiv: 1506.03134
   - Why: Foundational architecture — attention as pointer to input elements

2. **CopyNet** (Gu et al., 2016)
   - File: `1603.06393_copynet.pdf`
   - arXiv: 1603.06393
   - Why: Introduced generate/copy mode mixture with shared softmax

3. **Get To The Point: Pointer-Generator Networks** (See et al., 2017)
   - File: `1704.04368_pointer_generator.pdf`
   - arXiv: 1704.04368
   - Why: Most directly relevant — explicit p_gen gate for copy decisions + coverage mechanism

4. **Pointer Sentinel Mixture Models** (Merity et al., 2016)
   - File: `1609.07843_pointer_sentinel.pdf`
   - arXiv: 1609.07843
   - Why: Sentinel-based gating for pointer vs. softmax in language modeling

5. **Pointing the Unknown Words** (Gulcehre et al., 2016)
   - File: `1603.08148_pointing_unknown_words.pdf`
   - arXiv: 1603.08148
   - Why: MLP-based switching network for pointer vs. vocabulary softmax
